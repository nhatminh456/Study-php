# Bài 9: Kiểm tra kiểu dữ liệu

# Mục tiêu 
 - Hiểu được các kiểu dữ liệu trong PHP
 - Biết cách kiểm tra kiểu dữ liệu của một biến
 - Biết cách chuyển đổi kiểu dữ liệu của một biến

# Cú pháp kiểm tra kiểu dữ liệu
 ```php
var_dump(); kiểm tra kiểu dữ liệu của một biến
```
