# Bài 1: Hello World

# Mục tiêu

Sau bài này, bạn có thể:

- Nhận biết cấu trúc cơ bản của một file PHP.
- Sử dụng `echo` để in dữ liệu.
- Chạy một chương trình PHP đơn giản.

# Cấu trúc file PHP

Một chương trình PHP thường bắt đầu bằng thẻ mở:

```php
<?php
```

Code PHP được viết sau thẻ này. Có thể bỏ thẻ đóng `?>` khi file chỉ chứa PHP.

# In dữ liệu bằng `echo`

`echo` dùng để đưa dữ liệu ra màn hình:

```php
<?php

echo "Hello, world!";
```

Chuỗi phải được đặt trong dấu nháy đơn hoặc dấu nháy kép. Mỗi câu lệnh thường kết thúc bằng dấu chấm phẩy `;`.

# Ghi chú

Ghi chú giúp giải thích code và không được PHP thực thi:

```php
// Đây là ghi chú một dòng

/*
   Đây là ghi chú nhiều dòng
*/
```

# Lỗi thường gặp

- Quên `<?php`.
- Quên dấu `;`.
- Viết sai tên file hoặc chạy sai thư mục.
- Đặt chuỗi thiếu dấu nháy.
