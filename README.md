## Sau khóa học này, bạn sẽ đạt được gì?

### Giai đoạn 1: Nền tảng PHP 
- Tự cài đặt môi trường và chạy được chương trình PHP trên máy mà không cần XAMPP.
- Nắm vững cú pháp cơ bản: biến, hằng số, kiểu dữ liệu, chuỗi và toán tử.
- Viết được chương trình có điều kiện và vòng lặp để xử lý logic.
- Làm việc thành thạo với mảng và các hàm xử lý mảng.
- Biết tự viết hàm để tái sử dụng code và chia chương trình thành nhiều file.

### Giai đoạn 2: Web PHP 
- Xây dựng được form nhận dữ liệu từ người dùng bằng GET và POST.
- Kiểm tra và làm sạch dữ liệu đầu vào trước khi xử lý.
- Xử lý upload file, cookie và session (ghi nhớ trạng thái người dùng).
- Làm việc với ngày giờ và biết cách tìm, sửa lỗi (debug) khi chương trình chạy sai.

### Giai đoạn 3: Lập trình hướng đối tượng (OOP)
- Hiểu và áp dụng class, object, kế thừa, interface và trait.
- Tổ chức code gọn gàng, dễ bảo trì và dễ mở rộng.

### Giai đoạn 4: Cơ sở dữ liệu
- Viết được các câu lệnh SQL cơ bản và kết nối MySQL bằng PDO.
- Xây dựng chức năng thêm, xem, sửa, xóa (CRUD) hoàn chỉnh.
- Biết chống SQL Injection và làm chức năng đăng ký, đăng nhập an toàn.

### Giai đoạn 5: Kỹ năng chuyên nghiệp
- Sử dụng Composer, Git và tổ chức dự án theo mô hình MVC.
- Hiểu các lỗ hổng bảo mật phổ biến (XSS, CSRF) và cách phòng tránh.
- Xây dựng được API trả về JSON.

### Kết quả cuối cùng
- Tự làm được một website PHP hoàn chỉnh từ đầu đến cuối.
- Có nền tảng vững để học tiếp framework như Laravel.
- Có sản phẩm thực tế để đưa vào hồ sơ và portfolio.
